Política de privacidad

Asistente personal · Última actualización: 11 de noviembre de 2026

1. Qué datos se usan

Con la autorización del usuario, mediante el inicio de sesión de Google, el asistente accede a:

  • Google Calendar: leer, crear, modificar y borrar eventos del calendario del usuario.
  • Gmail: leer el remitente, el asunto y el contenido de los correos recientes de la bandeja de entrada, solo para detectar los que son importantes. El asistente no envía, borra ni modifica correos.
  • Google Sheets y Drive: crear y actualizar la planilla de gastos del propio usuario.

También se guardan los mensajes, audios, fotos y documentos que el usuario envía al asistente por Telegram.

2. Para qué se usan

Los datos se usan únicamente para prestar el servicio al mismo usuario: armar su resumen diario, recordarle sus eventos, proponerle guardar correos importantes y llevar el registro de sus gastos.

3. Con quién se comparten

  • Los datos no se venden ni se comparten con terceros con fines comerciales o publicitarios.
  • Para entender textos, audios e imágenes, se envían fragmentos al servicio de inteligencia artificial Gemini de Google, solo para procesar esa solicitud.
  • Los mensajes se reciben y envían a través de Telegram.

4. Uso de datos de las API de Google

El uso que hace este asistente de la información recibida de las API de Google cumple con la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado. Los datos de Google no se usan para publicidad ni para entrenar modelos de inteligencia artificial generales.

5. Dónde se guardan y por cuánto tiempo

Los datos se guardan en un servidor privado administrado por el responsable del servicio, con acceso restringido. Los registros técnicos se borran a los 7 días. Los gastos, tareas y eventos se conservan mientras el usuario use el servicio.

6. Derechos del usuario

El usuario puede en cualquier momento:

  • Retirar el acceso desde la configuración de su cuenta de Google.
  • Pedir una copia de sus datos o su eliminación completa escribiendo al contacto de abajo. La eliminación se realiza dentro de 30 días.
